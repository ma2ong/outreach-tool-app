＃ 96 — 韩语信叫职位，不叫名字

## Allen 的话（09-03）

> 韩国客户如果只知道对方的名字的话不要直接称呼对方名字。例如 윤주영，不能说
> 안녕하세요, 윤주영님。一定要知道对方职位的情况下才加上对方的职位……如果不知道对方
> 的职位的情况下就算知道对方的名字也不要称呼对方的名称，直接说 안녕하세요。

## 这不是一条新偏好，是一封正在发错的信

十二个韩语步骤的第一行全是 `안녕하세요, {contact}님.`，而 **129 家韩国客户库里
有名字**。那些信正以「안녕하세요, 김종수님.」发出去。

`personalize.py` 里还留着一行注释，说明这是刻意的：

> The lookbehind is what keeps "김종수님" intact: only an honorific with no name in
> front of it is an orphan.

当时解决的问题是对的（`안녕하세요, 님.` 是对着空气行礼），解决方式在韩国 B2B 冷邮件
里是错的：**陌生人之间不直呼姓名**，叫的是职位。

## R1：抬头那一格放职位，不放名字

模板不动（`안녕하세요, {contact}님.`）。判据是模板里出现 `{contact}님` —— 那就是
一个韩语敬称位置，这一格填职位。

* 知道职位 → `안녕하세요, 대표님.` / `과장님` / `차장님` / `이사님` / `상무님` / `대리님`
* 不知道职位 → `안녕하세요.` **知道名字也不叫**（既有的孤儿敬称清理正好落到这里）

英文信不受影响：`Hi {contact},` 照旧用名字，那是英文的礼貌。

## R2：职位是白名单，不是猜出来的

`Director`、`Manager`、`International Sales`、`Exhibition Contact` 一律落空。

理由是韩国的职级是具体的：**부장 和 과장 差两级**，从一个笼统的英文头衔猜是哪一级，
猜错比不称呼更糟。这条和 docs/95 R3 是同一条规矩的另一面 —— 不确定就不说。

唯一从英文映射的是 `CEO / President / Owner / Founder → 대표`，这一条在韩国公司里
是稳的：老板名片上印的就是 대표。名片上的 `대표이사` 当面叫 `대표님`。

职位从 `title`、`contact_name`（库里存着「이종윤 부장」这种）和 `role` 里找。

## 验收

1. `{"contact_name": "윤주영"}` → `안녕하세요.`
2. `{"contact_name": "윤주영", "title": "대표"}` → `안녕하세요, 대표님.`
3. `title` 是 `CEO` / `President` → `대표님`；`대표이사` → `대표님`
4. `title` 是 `Director` / `Manager` / `International Sales` → `안녕하세요.`
5. `contact_name` 是「이종윤 부장」而 `title` 为空 → `안녕하세요, 부장님.`
6. 英文模板 `Hi {contact},` 仍然渲染出 `Hi Michael,`

## 没做的

* **不去猜职级。** 见 R2。
* **不改模板。** 十二个韩语步骤一个字不动 —— 要改的是那一格填什么。
