# 44 — Agent-Owned Work Queue

## Goal

Sales Tasks must mean work the human actually has to do. Routine public-data work that
the autonomous sales operator can complete safely must be owned and consumed by the
Agent instead of becoming a growing human to-do list.

## Ownership

`activities.work_owner` is additive and defaults to `human`.

- `human`: pricing, quotation terms, payment, delivery, warranty, negotiation, explicit
  manual tasks, customer-reply takeovers, or ambiguous commercial judgement.
- `agent`: traceable routine research generated by Account Brain / Decision Maker Radar.

Historic Agent tasks may be reclassified only when exact proposal/task provenance exists.
Titles are never used to infer ownership.

## Autonomous research

The Worker may execute these Account Brain rules without human approval:

- `refresh_icp`: reread the company website and apply evidence-backed ICP classification;
- `find_decision_maker`: run the source-backed Decision Maker Radar;
- `replace_invalid_channel`: reread company-owned pages and repair a dead contact channel
  only from explicit public evidence, then reuse the existing email verifier;
- `verify_company`: replace junk/page-title company names using the existing safe resolver.

Weak/absent evidence is not invented. The Agent reschedules its own task for a later
retry; it does not transfer routine research to the human queue.

Decision Maker Radar may keep low-confidence candidates for later rescans. A title can
count as authority coverage, but the Agent does not silently set CRM `role=decision_maker`.

## UI semantics

The Sales Tasks page defaults to `需要我处理`. `Agent处理中` is a separate read-only
operating queue. The sidebar task badge uses human-owned overdue/today counts only.

## Safety boundary

This feature does not add a customer-send path. Email/social sends continue through the
existing guarded send/reply/sequence systems. It does not autonomously set or promise
price, discount, payment terms, Incoterm, delivery date, lead time, warranty, or formal
quotation terms.

## Failure behavior

Live public research is bounded per Worker cycle. One dead website does not block other
accounts. Transient failures are rescheduled in the Agent queue with an audit note.
